# VIO 能力边界

回答一个问题：**"VIO 到底有没有问题？"**

结论：**算法和输入数据没问题，工程实现有问题。** 本文用离线重算的实测数据划清这条界线。

> **修订说明**：本文初版的重算结果有误 —— 格式转换时把 `imu.csv` 的加速度轴与角速度轴对调了，导致重算时喂进去的加速度模长只有 1.2 m/s²（应为 9.8），初始化必然失败。修正后重跑，VIO 表现**显著好于此前的判断**。以下为修正后的数据。

---

## 一、离线重算实验

### 实验设计

用事故当时的**原始双目图像 + 原始 IMU**，在机载设备上离线重跑 ORB-SLAM3，与当时在线运行的结果对比。

如果当时是"VIO 算错了"，重算应该复现同样的错误；如果重算正常，说明问题在别处。

**输入**：滚动录制冻结的事件目录，每个约 20 秒、285 帧、15 fps 双目 640×480 灰度 + 200 Hz 陀螺 / 100 Hz 加计。

**格式转换**：滚动录制是 `frame_xxx/{left.png,right.png,frame.csv,imu.csv}`，replay 要求 `stereo.csv` + 根 `imu.csv` + `index` 从 0 连续。

> **关键坑**：`RollingInputRecording.cc:159` 写入顺序是 `t, a.x, a.y, a.z, w.x, w.y, w.z` —— **加速度在前、角速度在后**。与目标格式列序一致，转换时不能重排。校验方法：`|a|` 应约 9.8 m/s²。

## 二、VIO 能做什么（有证据）

| 能力 | 证据 |
|---|---|
| 特征提取与跟踪 | `features = 1000 ~ 1009`，全程稳定不衰减 |
| 双目匹配与三角化 | 重算位置平滑，稳态单帧位移 < 0.1 m |
| IMU 预积分 | 200 Hz 陀螺 / 100 Hz 加计，频率正常 |
| **连续跟踪能力** | **拼接 127.7 秒，`tracking` 掉出 0 次** |
| IMU 初始化（VIBA1 / mTinit） | 3.0–3.4 s（三组回放一致） |
| **VIBA2 完成** | 飞行中 **11.0 s**；从悬停起步 **18.9 s**；纯悬停 20 s **未完成**（见 §3.1） |
| 短时静止精度 | 历史数据：静止 649.9 秒漂移 **0.0 cm/s**；静置 1220 秒只漂 0.4 cm |
| 输出频率 | `process_hz = 14.6 ~ 15.0`，稳定 15 fps |
| 与 EKF 一致性 | 定点悬停时 dH（VIO−EKF 水平差）**0.00 ~ 0.15 m** |
| 断流后恢复 | 47.5 s 数据空洞后重建地图（本轮实测 5 次重建）并继续跟踪 |

## 三、VIO 不能做什么（有证据）

### 3.1 完全静止无法初始化

`not enough acceleration` 出现在 `run.log` 的第 **123 ~ 2188 行**，即**初始化完成之前的所有时段**。

飞机在地面放置、电机不转时，加速度恒为重力，没有变化量，视觉惯性初始化无法启动。一旦开始手摇（第 2194 行 `inertial_initializing`），35 行内就完成初始化（第 2238 行首次 `publishing`）。

**但要注意**：这不是"能力缺陷"，是物理约束。而且修正后的重算证明，**飞行中（有电机振动 + 姿态变化）能正常初始化** —— 实验 B 的 127.7 秒全程稳跟踪就是证据。

所以准确表述是：

| 状态 | 能否完成 IMU 初始化 | 能否完成 VIBA2 |
|---|---|---|
| 地面放置、电机不转 | ❌ 不能（加速度恒定） | ❌ |
| 地面手摇/搬动 | ✅ 能（12 秒内） | ✅ |
| 空中机动/起飞段 | ✅ 能 | ✅ **11.0 s**（事故段实测） |
| **空中静默悬停** | ⚠️ 反复被 `Not enough motion` 打断 | ⚠️ **20 s 内完成不了**（N0 实测，`ba2` 全程 0） |
| 匀速平移 | ✅ 能（有振动） | ✅ |

**N0 的实测（2026-11-06 补做）**：`event_535187059_3003_0`，空中悬停 20 s，视觉跟踪 99.6 % 帧 OK、0 次 LOST，但 IMU 初始化被"运动不足"打断 **2 次**、地图重建 **3 次**，最后 `VIBA1` 完成了、`VIBA2` 一次都没到。同一批图像接上后面飞行的 6 段（NA），`ba2` 在 18.9 s 完成 —— 差别只在"后面有没有运动"。

这对门控的直接影响：`stable_seconds=1.0` / `max_age_seconds=0.25` 这类**短窗口**稳定性假设，在"悬停不动"时恰恰最不成立——VIO 此时可能正处于初始化回退状态，但它输出的 `valid` 仍然是 1、`tracking` 仍然是 OK。**光看这两个标志位判不出"初始化其实没完成"。**

### 3.2 快速转向会掉高

历史实测（10931 个帧对按偏航角速度分桶）：

| 偏航角速度 | dz/dt 中位数 | 下沉占比 |
|---|---|---|
| 0~11 °/s | +0.03 cm/s | 39% |
| 29~57 °/s | +1.42 cm/s | 39% |
| **57~115 °/s** | **−0.81 cm/s** | 56% |
| **>115 °/s** | **−6.64 cm/s** | **77%** |

拐点在 **57°/s**。机理：快转时画面整体平移，ORB 特征大量失效，双目尺度约束和重力观测同时变弱。

### 3.3 尺度可能崩溃

历史案例：单帧位置跳 67 m，X 到 **−344 m**，644 次跳变。

### 3.4 高负载会丢帧

| 配置 | 实测帧率 | 丢帧率 |
|---|---|---|
| 1250 特征 @ 30 fps | 26.5 fps | **11.7%** |
| 1000 特征 @ 15 fps | 15.0 fps | 0% |

CPU 是瓶颈，不是相机（相机实测 29 fps@30、58 fps@60，一帧不缺）。

### 3.5 输出频率会随时间衰减

历史实测：16.3 Hz → 5.5 Hz（10 分钟内）。不是热降频（4 核满频、49°C），怀疑是地图/关键帧膨胀让局部 BA 变慢。

## 五、划分界线

| 层 | 结论 | 依据 |
|---|---|---|
| ORB-SLAM3 跟踪算法 | ✅ 没问题 | 拼接 1091 帧，`tracking` 掉出 **0 次** |
| 双目三角化 / IMU 预积分 | ✅ 没问题 | 重算位置平滑，单帧 < 0.1 m 稳态 |
| 图像与 IMU 数据质量 | ✅ 没问题 | 修正列序后 97.2% 帧有效（1060/1091） |
| 初始化鲁棒性 | ⚠️ 物理约束 | 地面静止无法启动；**空中静默悬停 20 s 也完不成 VIBA2**（实验 C） |
| 快速转向精度 | ❌ 有缺陷 | >57°/s 掉高 |
| **门控阈值** | ❌ **有问题** | 三个门限比实测低 19%~256% |
| **处理速度** | ❌ **有问题** | `track_ms` 77 ms > 帧间隔 66.7 ms |
| **故障处理策略** | ❌ **有问题** | 5 条路径全部一次性永久锁存 |
| **时钟部署** | ❌ **有问题** | 每次开机 1970 |

## 六、一句话总结

> VIO 的"算法和输入数据"没问题，"我们的工程实现"有问题。

2026-11-05 漂 102 米，不是 VIO 算错位置，而是**门控在 RTT 抖动 20.4 ms 的那一帧把 VIO 关了，然后再也没打开**。`track_ms` 逼近帧间隔造成的 1 秒空洞是压垮它的最后一击。

VIO 在被关掉之前，一直是 98% 以上正常的。

## 七、复现这几次实验

```bash
# 1) 转换格式（注意：不要重排 IMU 列）
python scripts/convert_rolling.py <event_dir> /tmp/conv

# 2) 校验 IMU 单位：|a| 应约 9.8 m/s²
python -c "
import math
for ln in list(open('/tmp/conv/imu.csv'))[1:4]:
    v=[float(x) for ln2 in [ln] for x in ln2.split(',')]
    print('|a| =', round(math.sqrt(v[2]**2+v[3]**2+v[4]**2),3))
"

# 3) 重算
ORB_REPLAY_UNPACED=1 d435i_recovery_replay \
  Vocabulary/ORBvoc.txt /tmp/conv/settings.yaml /tmp/conv /tmp/out

# 4) 看结果
# navigation.csv 列: index,timestamp,valid,tracking,imu,ba2,...
awk -F, 'NR>1 && $3==1' /tmp/out/navigation.csv | wc -l   # 有效位姿数
```
