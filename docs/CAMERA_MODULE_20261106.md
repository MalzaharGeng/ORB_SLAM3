## 五、由标称值推导的量（推算，非标定）

### 1. 2720×960 应为左右目各 1360×960 拼接

三条标称值只有在这个假设下才自洽：

- 焦距像素数：`f_px = 2.0 mm / 3.0 µm = 666.7 px`
- 若按单幅 2720×960 计算，对角视场 `2·atan(√(2720²+960²) / (2×666.7)) ≈ 130°`，与 102° 不符
- 若按单目 1360×960 计算，对角视场 `2·atan(√(1360²+960²) / (2×666.7)) ≈ 102.6°`，与标称 102° 吻合
- 靶面尺寸同样支持这个判断：单目 1360×3.0 µm = 4.08 mm 宽、960×3.0 µm = 2.88 mm 高，与 1/3.7"（约 4.0×3.0 mm）同量级；若按单幅 2720，宽度 8.16 mm，远超 1/3.7" 靶面

因此更可能是双目模组，驱动输出一帧 2720×960，左右目并排拼接。**这一点需向厂商确认**；若实际是单幅 2720×960，第五节其余推算全部失效。

### 2. 单目理论内参（针孔近似，未含畸变）

| 参数 | 推算值 | 依据 |
|---|---|---|
| `fx`, `fy` | ≈ 666.7 px | 2.0 mm / 3.0 µm |
| `cx`, `cy` | ≈ 680, 480 px | 假定光轴落在单目图像中心 |
| 水平 FOV | ≈ 91.1° | 1360 px 宽 |
| 垂直 FOV | ≈ 71.5° | 960 px 高 |
| 对角 FOV | ≈ 102.6° | 与标称 102° 一致 |

这些值只能用于判断量级和做标定初值，**不能直接写进 ORB-SLAM3 配置**。

### 3. 基线未知

双 M12 镜头，模组外形与两光心间距都没有给。`Stereo.b`、`bf` 无法推算，必须实测：卡尺量光心距只能作初值，最终以标定结果为准。

### 4. 拼接帧的取图方式未知

若驱动输出单帧 2720×960，采集端需要按 x 方向切成左右两幅 1360×960。切分边界、左右顺序、两目同步误差都要实测确认，不能假定左半就是左目。

## 六、与当前 D435i 配置的差异

| 项 | D435i（2026-11-06 前） | 本模组（当前在用） | 影响 |
|---|---|---|---|
| 分辨率 | 640×480 双目红外 | 2720×960（推断为 2×1360×960） | 帧尺寸、特征数、算力需求变化大 |
| 帧率 | 15 fps（`Camera.fps` 配置值） | 120 fps MJPEG / 60 fps YUYV | 需降帧或抽帧，MJPEG 还要解码 |
| 快门 | 全局快门（红外双目） | 全局快门 | 无本质差异 |
| 深度来源 | 主动红外立体 | 纯双目 | 无红外投射，弱纹理场景退化更明显 |
| IMU | BMI055（D435i 内置） | LSM6DSV | 噪声参数、频率、外参全部要重测 |
| 驱动 | librealsense 2.56.5 | UVC / V4L2 | 采集代码不通用 |
| 时间戳 | librealsense 硬件时间 | UVC 帧时间戳，精度待测 | 影响 VIO 的相机-IMU 同步 |

## 七、接入前必须补齐

1. 单目内参与畸变：`Camera1.fx/fy/cx/cy/k1/k2/p1/p2`，视场大时还要 k3
2. 双目基线 `Stereo.b` 与 `T_c1_c2`
3. 相机-IMU 外参 `IMU.T_b_c1`
4. IMU 噪声与频率：`IMU.NoiseGyro/NoiseAcc/GyroWalk/AccWalk/Frequency`
5. 相机与 IMU 的时间同步方式、时间戳基准
6. 实际取流分辨率、左右目切分与顺序、曝光/增益锁定策略
7. 换相机后重测 `config/px4_vio.yaml` 的 `R_BI` 与飞控 `EKF2_EV_POS_X/Y/Z`

## 八、边界与禁止事项

- 本文所有数值来自厂商规格书，**未经标定验证**；第五节的 fx/fy/cx/cy 是针孔近似推算，不能作为运行参数。
- 不得把本模组的规格值直接写进 `Examples/Stereo-Inertial/CModel.yaml`，也不得在未标定的情况下用于实飞。2026-11-05 两次事故的复盘结论全部基于 D435i；本次已发生硬件替换，2026-11-06 之后的图像与位姿数据不能与 11-05 的数据直接对比，需要重新建立基线。
- 102° 只有按对角理解才与 2.0 mm / 3.0 µm 自洽；若厂商实际指水平视场，第五节推算作废，需向厂商确认。
- `Image area`、最低照度、IMU 具体型号后缀与输出频率、基线长度均为 TBD，本文不填猜测值。
