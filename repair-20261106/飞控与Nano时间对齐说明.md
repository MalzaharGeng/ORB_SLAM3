# 飞控 ULog 与 Nano 内录时间对齐

本次重新从原始消息和历史事件元数据建立对应，未使用文件名中的1970年作为时间依据，未修改机载运行配置。

## 对齐依据

1. 对两份 ULog 的 vehicle_attitude 四元数与 Nano ROS 内录 attitude 的 payload 逐条匹配。第一次找到2817条相同消息，最后一次找到652条相同消息。
2. 最后一次匹配的 Nano消息时间减PX4原始时间中位数为0.936143秒，匹配值范围0.935839–0.936567秒。这是时钟域偏移，**不是约0.94秒的通信延迟，也不是物理图像/IMU对时误差**。按时间插值该偏移，用于帧索引转换。
3. 遥控杆量匹配提供附加交叉核对。相同中立杆量可能重复，先由姿态消息确定时钟域偏移，再仅保留该偏移附近的唯一候选。不能直接用重复中立杆量做无约束配对。
4. 原始图像事件 event_1603810252_3003_6 保存的 clock_origin.txt 明确写有 sensor_time_origin_system_seconds=230.942017，以及 image_system_seconds=image_timestamp+sensor_time_origin_system_seconds。事件中286帧的frame.csv及115帧overview元数据均已读取归档。
5. 将图像时间恢复到Nano样本时钟后，286帧中284帧能以sample_us在约1微秒舍入容差内直接找到Nano实际发布记录。这是时间原点的额外交叉验证，不是说图像物理曝光对时精度达到1微秒。

## 最后一次飞行的转换

ULog起点为PX4 timestamp=1559796718微秒。用中位数偏移表示的近似关系：

```
Nano样本秒 = 图像秒 + 230.942017
PX4开机秒 ≈ Nano样本秒 - 0.936143
ULog相对秒 = PX4开机秒 - 1559.796718

图像秒 ≈ ULog相对秒 + 1329.790844
```

实际CSV索引用匹配消息的随时间变化偏移插值；上式适用于快速定位。

## 已保存数据的覆盖范围

| 数据 | 对应最后一次ULog时间 | 限制 |
|---|---|---|
| 全程Nano ROS遥测CSV | 覆盖整次飞行 | 多话题频率不同，接收时刻不能代替采样时刻 |
| 286组全帧双目图像+逐帧IMU批 | 23.0804–43.0156秒 | 是保留事件内的帧，不保证无采集/录制缺口 |
| 115组低频背景图像 | −76.3913–42.3489秒 | 约1Hz，包含起飞前与本次前段；不能当成连续惯性输入完整重放 |

之前的“ULog t=0对应图像1329.2秒”是粗对齐，和本次基于原始时钟元数据的关系相差约0.591秒。后续判断先后顺序应使用本次新索引。已有旧图表/旧报告未被覆盖，不应据旧偏移做亚秒级因果判断。

第16.48–17.48秒制动片段，在全程Nano ROS遥测中有对应，但不在保存的全帧事件中。低频背景图有附近快照，例如ULog约16.9476秒和17.9476秒，分别对应overview/frame_000000019521和frame_000000019536；这些不是精确落在两个制动端点的照片，不能用1Hz照片判断0.2秒级姿态响应。

## 结果文件

- `last_flight_frame_alignment.csv`：每个原始帧/低频背景帧的ULog时间、图像时间、原始帧目录，以及最近的遥控输入和飞控位置/速度；同时记录被关联飞控消息的年龄。
- `flight_nano_alignment.json`：两次飞行共同消息匹配统计及经过时钟域转换的模式/解锁边沿。
- `14_07_14_message_matches.csv`：最后一次652条共同姿态消息的对应关系。
- `historical_frame_metadata.json`：历史事件时钟原点、286帧全帧元数据和115帧背景元数据。
- `last_flight_alignment_summary.json`：覆盖范围及关键秒数最近可用图像。

时间对齐可以用来联合核对“杆量→目标姿态→估计实际姿态→图像场景运动→落地”，但不自动证明VIO精度、遥控映射和事故原因；仍需区分各数据是否独立真值。
